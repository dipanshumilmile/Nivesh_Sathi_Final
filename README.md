# Nivesh Sathi

Nivesh Sathi is an intelligent investment advisory platform designed to assist users in making data-driven financial decisions. The application combines a modern web interface, scalable backend services, and machine learning models to provide stock analysis, investment recommendations, portfolio insights, and predictive analytics.

## Features
- Stock market analysis
- AI-powered investment recommendations
- Portfolio tracking and insights
- Machine learning-based predictions
- Secure and scalable architecture
- Responsive user interface
